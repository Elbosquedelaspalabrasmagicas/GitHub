# 🌳 El Bosque de las Palabras Mágicas

Videojuego educativo para primer grado de primaria, orientado al desarrollo de la conciencia fonológica y la iniciación a la lectoescritura.

## 🎮 Publicar en GitHub Pages

### Opción recomendada: subir los archivos directamente al repositorio

1. Entra a **GitHub** e inicia sesión.
2. Crea un repositorio nuevo, por ejemplo: `el-bosque-de-las-palabras-magicas`.
3. Puedes dejarlo como **Public**.
4. En el repositorio selecciona **Add file → Upload files**.
5. Abre la carpeta de este proyecto y sube estos elementos que están en la raíz:
   - `index.html`
   - `juego_web.tar.gz`
   - `favicon.png`
   - `version.txt`
   - `.nojekyll`
6. Pulsa **Commit changes**.
7. En GitHub abre **Settings → Pages**.
8. En **Build and deployment**, selecciona **Deploy from a branch**.
9. Selecciona la rama `main` y la carpeta `/ (root)`.
10. Pulsa **Save**.
11. GitHub generará una dirección parecida a:

`https://TU-USUARIO.github.io/el-bosque-de-las-palabras-magicas/`

> El nombre exacto del enlace depende del nombre de usuario y del repositorio que elijas.

## 📁 Archivos del proyecto

- `index.html`: página web de entrada y configuración de Pygbag.
- `juego_web.tar.gz`: paquete que contiene el videojuego para navegador.
- `favicon.png`: icono del juego.
- `assets/main.py`: código fuente Python/Pygame.
- `build/web/`: copia del build web.

## 📚 Propósito pedagógico

El juego trabaja tres retos progresivos:

1. **El Río de las Vocales:** reconocimiento de A, E, I, O y U.
2. **El Puente Silábico:** combinación consonante + vocal con m, p, s y l.
3. **El Gran Árbol de las Palabras:** construcción y lectura de palabras cortas como MESA, LUPA y PATO.

No se utilizan penalizaciones de vidas: los errores reciben retroalimentación formativa y positiva.

## 🧩 Método de lectura

El enfoque es principalmente **fonético-silábico**, avanzando desde sonidos vocálicos hacia sílabas directas y posteriormente palabras sencillas.
